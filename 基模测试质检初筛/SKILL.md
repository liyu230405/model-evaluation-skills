# 基模测试质检初筛

## 这个 skill 做什么

测试员对每个用例（FT-xx-x）测 5 次（T1 到 T5），每次给 0/1/2 分并选标签，写测试详情（判词）。这个 skill 做三件事：

1. 按固定规则分档，告诉 QC 哪些要看、为什么。
2. 生成逐用例回执，追踪「推荐 → 复核 → 是否修改 → 修改类型」；退回项不处理就一直未闭环。
3. 用原版/终版对比计算精确精度与召回，用盲抽回执估计漏检；改分、改标签、改判词都算改动。

**不判分、不改分、不建议改成几分，不替 QC 做裁决。** 历史异常只表示值得复核，不表示当前结果错误。

## 输入与前置检查

当前打开的飞书表格里，一个 sheet 就是一个模型的一批测试。每个用例占一行，列包括：用例ID、prompt_ch、T1_分数/T1_标签/T1_测试详情（T2 到 T5 同名）、测试员或测试人员。分数是 0、1、2 或空；多个标签按逗号、顿号、分号、斜杠或空格拆分。

开始前确认：
1. 用户没说筛哪个 sheet 就问，不要自己挑。
2. 如果 sheet 已被 QC 改过，结果只能说明当前风险，不能当作 QC 前初筛效果。
3. 同一用例出现多块时只筛第一块，并列出重复用例。
4. 缺少用例ID或 T 系列列时停下来说明，不要猜列。
5. 做闭环时必须有 QC 前原版和 QC 后终版，或填写完整的 `_复核回执.csv`。没有回执就不能声称已算精度、召回或漏检。

## 分档规则

逐用例、逐试验检查，命中多条就全部列出。一次试验取最高档，同一用例取各次最高档：**退回 > 必复核 > 抽检 > 通过**。

完整出处见 `规则表.md`。简表：

| 编号 | 档位 | 条件 |
|---|---|---|
| R1 | 退回 | 分数不是 0、1、2（空不算） |
| R2 | 退回 | 标签不在 13 个标准标签和「其他」内 |
| R3 | 退回 | 「无有效动作」与其他标签共存，或分数为 1/2；共存部分由矩阵判定 |
| R4 | 退回 | 「重试完成」+「部分完成」 |
| R5 | 退回 | 「部分完成」+「质量瑕疵」 |
| R6 | 退回 | 「结果失效」+「质量瑕疵」 |
| R7 | 退回 | 「部分完成」+ 任一具体失败标签 |
| R8 | 退回 | 「质量瑕疵」+「动作精度不足」 |
| R9 | 退回 | 0 分或 1 分但测试详情为空 |
| R10 | 退回 | 任一具体失败标签 +「重试完成」 |
| R11 | 退回 | 任一具体失败标签 +「过度执行」 |
| R12 | 退回 | 「部分完成」+「过度执行」：当前指令未完成与已完成相矛盾 |
| V1 | 必复核 | 分数是 1 |
| V2 | 必复核 | 带「其他」 |
| V3 | 必复核 | 标签只有「部分完成」 |
| V4 | 必复核 | 测试员在用户给的新测试员名单里 |
| V5 | 必复核 | 历史试验数足够，且本次用例均分与历史校准期望分的绝对偏差达到阈值（默认 1.0） |
| S1 | 抽检 | 带「目标位置错误」 |
| S2 | 抽检 | 标签非空且全部是「碰撞/过度执行」，分数却不是 2 |
| S3 | 抽检 | 本次分数、标签、详情全空，但同用例其他次有内容 |
| S4 | 抽检 | 分数空但标签非空 |

**13 个标准标签**：重试完成、对象识别错误、目标位置错误、约束违背、动作方式不当、碰撞、动作精度不足、抓取失败、质量瑕疵、结果失效、无有效动作、过度执行、部分完成。另允许「其他」。

**具体失败标签**：抓取失败、动作精度不足、动作方式不当、对象识别错误、目标位置错误、结果失效、约束违背。

### 标签共存矩阵

`标签共存矩阵.csv` 是 R3 到 R8、R10 到 R12 的唯一共标判定来源，不要在逻辑里另写一套互斥条件。

- 行和列都是 13 个标准标签加「其他」；`✓` = 可共存，`—` = 自身对角线，规则编号 = 禁配并退回。
- 矩阵必须对称。新增冲突时同时改两个对称单元格；新增规则编号时同步补 `规则表.md` 和脚本 RULES。
- **共标检查与分数无关**：0 分、1 分、2 分、分数空都检查。不能因为 0 分就跳过标签清理。
- 报告除规则编号外，还要列出实际冲突组合，例如「抓取失败 + 重试完成 [R10]」。

### 历史均分如何进入判断

V5 是用例级异常信号，不是逐条判分规则：

```
期望分 = 历史均分 +（本 sheet 整体均分 − 历史整体均分），限制在 0 到 2
偏差 = 本次用例均分 − 期望分
```

历史试验数默认至少 5 次，且 `abs(偏差) >= 1.0` 时，该用例所有有分试验进必复核并标 V5。阈值和历史最少试验数可配置；没有历史就不触发。V5 不用于退回，不说明该改成几分。旧回测证明它不适合自动改分，因此只用于补充异常视野，效果要靠后续闭环重新评估。

### 容易判错的地方

- 分数空 + 详情有字 + 标签空 = 合法「不打分」，不命中规则。只有全空才是 S3，只有分数空但标签非空才是 S4。
- 整个用例 5 次全空：这批没测，直接跳过。
- R3 的分数约束只有 1/2 分命中，分数空不算；标签共存仍由矩阵独立检查。
- 标签名必须完全一致；错别字命中 R2。
- V3 是「只有」部分完成；「部分完成、碰撞」不命中 V3。
- 0 分本身不触发复核，但 **0 分中的非法标签组合仍触发 R 规则**。
- 判词文本变化不等于分数变化。compare 和回执必须单独记录「判词」，不能因分数没变就忽略。

## 怎么算

1. 读入 sheet，定位表头和 T1 到 T5 列；合并测试员单元格向下补全。
2. 逐条检查 R1 到 S4，其中所有共标由矩阵判定；记录实际冲突组合。
3. 有基线时按用例计算 V5，再合并档位。
4. 对全部「通过」的用例整行盲抽：默认 **20% 且至少 5 个**，用 sheet 名和用例顺序生成稳定随机种子；同一 sheet 重跑一致，不同批次不固定抽同一位置。用户可给种子或比例。
5. 输出复查报告、复核清单、逐条明细、复核回执和汇总。报告写清盲抽样本量，以及在目标漏检率下的发现概率；发现概率不足 80% 时不得据此宣称「没有漏检」。
6. QC 或测试员处理每条推荐后填写回执。运行 audit，未闭环项必须单独列出；要求严格闭环时，有未闭环项就失败。
7. 有原版和终版时运行 compare，按用例+T 配对。改分、改标签、判词文本变化分别统计，并单列「仅改判词」的召回。判词比较只做全半角统一和去空白，语义是否等价由 QC 判断。

## 输出与闭环

报告先写结论，再按档位分块；一个用例一行，T1 到 T5 并排，要看的次数加粗。退回项列出用例、T、分数、标签、冲突组合、详情。历史列显示历史均分、期望分和偏差。

`_复核回执.csv` 每个推荐或盲抽用例一行，字段包括：

| 字段 | 填写要求 |
|---|---|
| 批次、用例、推荐档位、命中规则、需看的T | 工具生成，不改推荐原值 |
| 状态 | 初始「待处理」，完成复核后才填「已复核」 |
| 是否修改 | 必填「是/否」；分数、标签、判词任一变化都算「是」 |
| 修改类型 | 修改时填「分数」「标签」「判词」之一或多个 |
| 复核人、复核时间 | 已复核时必填 |
| 备注 | 记录退回重测、争议或不修改原因 |
| 通过档用例总数、盲抽样本数 | 工具生成，用于漏检估计 |

闭环口径：
- 退回没有处理、状态不是已复核、是否修改未填、复核人/时间缺失、已修改但未填类型，全部算未闭环。
- 不能生成一份新报告就清掉旧待办；只有回执完整才算关闭。
- audit 输出未闭环清单、推荐项精度、盲抽发现漏检数、盲抽漏检率及 95% Wilson 区间、发现能力和下一批建议样本量。
- 推荐项全部闭环且有盲抽时，可外推估计整体召回；**抽样估计不是全量真值**。要精确召回必须 compare 原版与终版。
- 单批样本不足时跨批累计，不要把 0 个盲抽漏检写成 0 漏检率。

## 做完后必须自检

1. 每个用例只属于一个主档位；退回同时命中必复核时可在必复核表再次出现，但计数只算退回。
2. 1 分试验总数等于 V1 命中数；抽 3 个用例回数。
3. 每个退回都能对应原始分数、标签和具体规则；矩阵对称，0 分共标没有漏检。
4. 空分逐条确认是合法不打分、S3 还是 S4。
5. V5 只按用例触发，历史不足不触发，不把 V5 写成「应该改分」。
6. compare 中「仅改判词」也计入 QC 改动、漏检和召回；回执的修改类型包含判词。
7. 所有推荐和盲抽都有回执。宣称本批完成前，audit 的未闭环数必须为 0；否则列出责任项，不能交付为已完成。
8. 修改脚本后运行 `python3 test_prescreen.py -v`，覆盖 0 分共标、仅改判词、历史异常、盲抽和未闭环回归场景。

## 数据依据与局限

仓库不附带真实历史测试记录或效果统计。合成回归测试仅验证代码行为；规则效果、盲抽漏检和闭环质量应使用使用者自己的独立复核数据评估。

## 不要做的事

- 不改分、不建议改成几分，不用历史偏差自动裁决。
- 不凭用例名称或指令推断难度；难度只取基线表。
- 不把没测的用例报成问题，不把分数空但有详情报成问题。
- 不把判词语义是否等价交给字符串比较决定；工具只发现文本变化，QC 判断语义。
- 不把少量盲抽、未闭环回执或样本内旧统计包装成可靠的全量召回。

## 配套文件

- `规则表.md`：规则编号、条件、出处。
- `标签共存矩阵.csv`：所有标签共标检查的唯一来源。
- `baseline.json`：空白历史基线结构。若需历史偏差复核，请从自己有权使用的数据生成基线。
- `prescreen.py`、`脚本版说明.md`：screen / compare / audit / baseline。
- `test_prescreen.py`：可重复运行的合成回归测试。
- `原理与计算方法.md`：旧数据依据、v2 指标口径和局限。

# 规则表

规则与 `prescreen.py` 的 RULES 对应。档位优先：退回 > 必复核 > 抽检 > 通过。R3 到 R8、R10 到 R12 的标签共标由 `标签共存矩阵.csv` 统一判定，与分数无关。

| 编号 | 档位 | 命中条件 | 出处 |
|---|---|---|---|
| R1 | 退回 | 分数不是 0、1、2 | 评分规范 |
| R2 | 退回 | 标签不在 13 个标准标签和「其他」之内 | 评分规范 |
| R3 | 退回 | 「无有效动作」与其他标签共存，或分数为 1/2；共存由矩阵判定 | 评分规范、精简版 |
| R4 | 退回 | 「重试完成」与「部分完成」同时出现 | 评分规范；共存矩阵 |
| R5 | 退回 | 「部分完成」与「质量瑕疵」同时出现 | 评分规范；共存矩阵 |
| R6 | 退回 | 「结果失效」与「质量瑕疵」同时出现 | 评分规范；共存矩阵 |
| R7 | 退回 | 「部分完成」叠加任一具体失败标签 | 精简版；共存矩阵 |
| R8 | 退回 | 「质量瑕疵」与「动作精度不足」同时出现 | 标签定义；共存矩阵 |
| R9 | 退回 | 0 分、1 分没有填测试详情 | 记录完整性规则 |
| R10 | 退回 | 任一具体失败标签与「重试完成」共存；0 分也检查 | 标签定义；共存矩阵 |
| R11 | 退回 | 任一具体失败标签与「过度执行」共存；0 分也检查 | 标签定义；共存矩阵 |
| R12 | 退回 | 「部分完成」与「过度执行」共存：当前指令未完成与已完成相矛盾 | 标签定义；共存矩阵 |
| V1 | 必复核 | 1 分 | 边界分数需要人工复核 |
| V2 | 必复核 | 带「其他」标签 | 非标准标签需要人工复核 |
| V3 | 必复核 | 只打了「部分完成」 | 单一部分完成标签需要人工复核 |
| V4 | 必复核 | 新测试员的记录 | 方案 5.4；名单由 `--new-testers` 给出 |
| V5 | 必复核 | 历史试验数足够，且本次用例均分与历史校准期望分的绝对偏差达到阈值 | 历史偏差提示；默认阈值 1.0，只提示异常复核 |
| S1 | 抽检 | 带「目标位置错误」 | 标签定义与抽检覆盖要求 |
| S2 | 抽检 | 只有「碰撞」或「过度执行」标签却不是 2 分 | 文档里这两个标签只记录、不扣分 |
| S3 | 抽检 | 同一用例的 T1 到 T5 没填全 | 方案 5.1 |
| S4 | 抽检 | 没有分数却有标签 | 不打分的步骤分数栏应留空，只在测试详情写原因 |

13 个标准标签：重试完成、对象识别错误、目标位置错误、约束违背、动作方式不当、碰撞、动作精度不足、抓取失败、质量瑕疵、结果失效、无有效动作、过度执行、部分完成。另允许「其他」。

R7、R10、R11 的具体失败标签：动作方式不当、动作精度不足、对象识别错误、抓取失败、目标位置错误、约束违背、结果失效。

V5 公式：`期望分 = 历史均分 +（本 sheet 整体均分 − 历史整体均分）`，截到 [0,2]；默认历史至少 5 次且 `abs(本次用例均分 − 期望分) >= 1.0`。V5 只用例级必复核，不退回、不建议改分。

QC 改动口径：改分、改标签、判词文本变化都算改动；compare 单列「仅改判词」召回。

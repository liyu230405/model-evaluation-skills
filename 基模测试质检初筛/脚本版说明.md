# 基模测试质检初筛 v2：脚本版

给一个测试 sheet 分档，生成复核回执；对照原版/终版计算精确精度与召回；审计回执并输出未闭环和盲抽漏检估计。只用 Python 3 标准库。

判分和裁决仍由人做。脚本只推荐复核、发现标签规则违规和统计实际处理结果。

## 输出文件

`screen` 输出五个文件，文件名带时间戳，不覆盖旧结果：

| 文件 | 一行是什么 | 用途 |
|---|---|---|
| `_复查报告.md` | 一个用例一行，T1 到 T5 并排 | 先看这份；退回项含实际冲突组合 |
| `_复核清单.csv` | 一个用例一行 | QC 筛选、排序；含历史期望与偏差 |
| `_逐条明细.csv` | 一次试验一行 | 核对单条规则、分数、标签、判词 |
| `_复核回执.csv` | 一个推荐或盲抽用例一行 | **闭环必填**；初始全部为待处理 |
| `_汇总.md` | — | 档位、规则、测试员、盲抽发现能力 |

CSV 均为 utf-8-sig。`compare` 输出复核清单、逐条明细和汇总；`audit` 输出闭环汇总和未闭环清单。

## 1. 每天初筛

```bash
python3 prescreen.py screen 输入测试记录.xlsx \
  --sheet "261120-FT测试记录-xxx模型" \
  --baseline baseline.json
```

不写 `--sheet` 时用最后一个已打分 sheet。常用参数：

```bash
--new-testers 甲,乙             # 新测试员全部必复核
--rules-off V2                  # 临时关闭规则
--tag-matrix 标签共存矩阵.csv     # 默认读脚本同目录矩阵
--history-threshold 1.0         # V5 阈值；0 关闭历史异常复核
--history-min-n 5               # V5 最少历史试验数
--sample-rate 0.20              # 通过档盲抽 20%
--min-sample 5                  # 至少抽 5 个用例
--seed 20261116                 # 可选；否则按 sheet 内容生成稳定种子
-o out
```

盲抽按用例整行抽，默认可复现随机抽样，不再固定抽第 10、30、50 个。20% 只是默认工作量，不保证小批次能发现低比例漏检；汇总会给出目标漏检率下的发现概率，不足时应扩样或跨批累计。

## 2. 填写回执并强制闭环

每个退回、必复核、抽检、盲抽用例都有一行回执。处理后填写：

- `状态`：完成后改为「已复核」。
- `是否修改`：填「是/否」；改分、改标签、改判词任一项都算「是」。
- `修改类型`：修改时填「分数」「标签」「判词」之一或多个，用顿号分隔。
- `复核人、复核时间`：已复核时必填。
- `备注`：可写退回重测、争议和不修改原因。

运行审计：

```bash
python3 prescreen.py audit out/xxx_复核回执.csv --require-closed -o out
```

输出：

- 未闭环清单：退回没人处理、状态未改、是否修改未填、复核人/时间缺失、修改类型缺失都会保留。
- 推荐项精度：已复核的非盲抽推荐中，实际修改的比例。
- 盲抽漏检：盲抽中发现需要修改的用例数，含仅改判词。
- 盲抽漏检率与 95% Wilson 区间。
- 估计整体召回：推荐项全部闭环后，按盲抽结果外推通过档；这是抽样估计，不是全量真值。
- 当前发现能力与下一批建议样本量：默认目标是「真实漏检率 5% 时，以 80% 概率至少发现一个」。可用 `--target-miss-rate`、`--confidence` 调整。

`--require-closed` 下仍有未闭环项时，先写审计文件，再以退出码 2 失败，可接入流程卡点。

## 3. 原版 vs 终版：精确对账

QC 开始前保留原版，完成后运行：

```bash
python3 prescreen.py compare 原版测试记录.xlsx 终版测试记录.xlsx \
  --orig-sheet "xxx-原版" --final-sheet "xxx" \
  --baseline baseline.json --tag-matrix 标签共存矩阵.csv
```

v2 将三类变化都计为 QC 改动：

1. 改分；
2. 改标签；
3. 改判词：全半角统一并去空白后，测试详情文本不同。

汇总单列改判词和「仅改判词」召回，因此分数不变但判词变化的记录也会统计。字符串比较只负责发现文本变化，语义是否等价由 QC 判断。

精确召回以全量原版/终版对账为准；audit 的抽样估计不能替代它。旧版历史回测只统计改分/改标签，不能直接当作 v2 召回。

## 4. 标签共存矩阵

`标签共存矩阵.csv` 是共标规则唯一来源：

- `✓`：可共存；`—`：对角线；`R3`～`R8`、`R10`、`R11`：冲突并退回。
- 矩阵必须对称，行列表头必须恰好是 13 个标准标签加「其他」。
- 新增冲突改两个对称单元格；新增规则编号还要同步 RULES 和 `规则表.md`。
- 所有分数都检查，包括 0 分。R10 覆盖「具体失败标签 + 重试完成」，R11 覆盖「具体失败标签 + 过度执行」。

## 5. 历史基线

定期重建：

```bash
python3 prescreen.py baseline 历史测试记录.xlsx -o baseline.json
```

V5 用下式做用例级异常复核：

```text
期望分 = 历史均分 +（本 sheet 整体均分 − 历史整体均分），截到 [0,2]
偏差 = 本次用例均分 − 期望分
```

默认历史至少 5 次且绝对偏差达到 1.0 才标 V5。它只进必复核，不退回、不建议改分；没有历史不触发。旧回测显示期望分偏离不适合自动改分，v2 只把它作为补充异常信号，实际精度需用新回执评估。

## 6. 回归测试

```bash
python3 test_prescreen.py -v
python3 -m py_compile prescreen.py
```

合成测试覆盖：0 分的 R10/R11、原 R3～R8、历史 V5、可复现盲抽、仅改判词、退回未闭环、回执精度/召回估计和回执文件生成。测试数据不代表真实 sheet 的判分或新规则效果。

## 旧回测数字的使用边界

仓库不包含历史回测结果。规则效果需在独立数据上重新计算，不能用合成回归测试代替。

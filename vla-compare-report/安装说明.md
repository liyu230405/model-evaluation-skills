# 安装说明（给使用者）

这是一个**技能包**：装进 AI 助手的技能目录后，你用一句自然语言就能出 VLA 评测报告，不用记命令。

## 装四步

1. **装环境**：Node 18+、Python 3（`pip3 install numpy scipy`）、`lark-cli` 并用自己的飞书账号登录。
2. **放目录**：把整个 `vla-compare-report/` 文件夹放进你的 AI 助手的**技能根目录**（Claude Code 是 `~/.claude/skills/`，其他产品见各自文档）。
3. **查权限**：你的账号要被加为两本多维表格的协作者，否则读表会 403。
4. **验一遍**（不需要任何真实权限）：

   ```bash
   node "<技能目录>/cli.js" --lock-status
   node "<技能目录>/cli.js" "<技能目录>/example/基模测试记录-示例.xlsx" \
     "<技能目录>/example/基模黑盒场景测试记录-示例.xlsx" --models 基线模型 新模型 --out /tmp/demo
   python3 "<技能目录>/verify.py" /tmp/demo/*_结果.json
   ```

   三条依次是：`✅ 指纹一致`、出四份文件、`不一致 0 项`。
5. **交付形态**：报告最后一步会调 `publish.py` 发布成**飞书文档**，所以 `lark-cli` 要能建云文档（账号有云文档权限）。拿到的交付物是文档链接，本地 `.md` 只是中间稿。

## 怎么用（说人话就行）

- 「用我提供的两个表出报告，基线是模型A，对比模型B」→ 两模型对比
- 「同上，再加模型C」→ 三模型
- 「模型B 单独测成什么样」→ 单模型报告
- 拿不准模型名就说「先列出表里有哪些模型」

## 三条边界

| 事项 | 使用者 | 维护者 |
|---|---|---|
| 出报告、换模型、选类型 | ✅ | ✅ |
| 改 `engine/`、`verify.py`、`compute-lock.json` | ❌ 被锁硬拦 | 只在开发副本改，并 `--relock --reason` 留痕 |
| 报告输出位置 | 写自己的可写目录 | 同 |

看到 `❌ …：期望 xxx… 实际 yyy…` 不要手改文件，也不要试 `--relock`——那是维护者的操作。把差异原样发给维护者，换一份干净安装包即可。

## 出问题先看这三个

- **403 / 无权限** → 账号没被加协作者，找管理员，别换身份绕。
- **没找到模型「X」** → 先用 `--list` 看真实模型名（子表名会带日期和 `FT测试记录-` 前缀，程序会剥）。
- **输出目录写入失败** → 写到了只读的技能目录，改写到自己的可写目录。

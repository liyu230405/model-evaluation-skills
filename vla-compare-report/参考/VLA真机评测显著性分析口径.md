# VLA 真机评测显著性分析口径

> 📌 **怎么报**：指标差值 + 90% 置信区间 + p 值 + 方向计数。使用本轮程序实际计算的数值，不从示例或历史报告复制。
>
> **显著性门槛：p<0.10（双侧）**。真机评测样本量受成本限制，0.05 过严；代价是假阳性率 1/10，故须预先声明主结论切面。
>
> **两条边界**：把执行数当样本量是伪重复，会把不显著算成显著（见 A1）；ID 与 OOD 是独立设计的两批用例、难度不可比，**单模型的 ID-OOD 差距只报数、不报 p**（见 [A7](#a7-id-vs-ood-为何不可检验)）。

## 一、指标分工

| 指标 | 测什么 | 定位 |
|---|---|---|
| **满分率**（成功率） | 得 2 分的占比。成功 = 得 2 分，0/1 均记失败 | **主指标**，结论以它为准 |
| **有进展率** | 得分 ≥1 的占比，即"是否减少彻底失败" | 辅助，做检验 |
| **平均分** | 得分均值 [0,2]，任务完成度 | 辅助，做检验 |
| **pass@5** | 5 次中至少成 1 次 | 业务描述，**不报 p** |

> 💡 **三个指标算自同一批打分，是嵌套关系，不是三份独立证据。** 有进展率测 0→≥1 段，满分率测 →2 段，平均分是两者加权。改善只集中在前半段时，必然出现"有进展率 p 最小、满分率 p 最大"——这是结构性现象，**不能挑 p 值最小的那个用。**
>
> 结论应当是三者共同支持的那句话，例如"减少了彻底失败，但没有把更多任务推进到成功"。

## 二、怎么算

用**配对 t 检验**（双侧）。步骤：

1. **每个用例聚合成一个数。** 5 次执行 → 一个指标值。例：某用例 5 次得分 2/0/2/1/2 → 满分率 3/5=60%，平均分 1.4
2. **两模型相减，得到该用例的差值。** 例：B 模型 80% − A 模型 60% = +20pp
3. **对全部用例的差值做检验。** 52 个用例就有 52 个差值，检验它们的均值是否偏离 0
4. **算 90% 置信区间。** 差值均值 ± $t_{0.05,\,n-1} \times SD_d/\sqrt{n}$，即真实差异的可能范围

满分率、有进展率、平均分**三个指标都走同一流程**，只是第 1 步的聚合方式不同。

```python
# a、b 为两模型的用例级指标值数组
from scipy import stats
import numpy as np

d = np.array(b) - np.array(a)          # 用例级差值
t, p = stats.ttest_rel(b, a)           # 配对 t，双侧 p 值
lo, hi = stats.t.interval(0.90, len(d)-1,
                          loc=d.mean(),
                          scale=stats.sem(d))   # 90% 置信区间
```

## 三、Skill 层面怎么判断

看两件事：**有多少个用例发生了实质变化**（该用例成功次数变化 ≥2 次），以及**这些变化方向是否一致**。

| 情形 | 判定 |
|---|---|
| 多个用例实质变化、方向一致 | **构成证据** |
| 实质变化方向混杂 | **平均值无意义**，不可写成单向结论 |
| 仅 1 个用例实质变化 | **单点观测**，不足为证 |
| 无实质变化（仅差 1 次执行） | 噪声 |

> 📌 **标准必须对正负对称施加。** 只有 1 个用例实质上升的 skill（+60pp）与只有 1 个用例实质下降的 skill（-40pp），**证据强度完全相同**，不能因为方向符合预期就采信其中一个。

## 四、能看出多大的差异

这套评测有个分辨能力下限，**比它小的差异看不出来**。按本项目采用的 p<0.10，典型下限是：

| 指标 | ID（n=52） | OOD（n=27） |
|---|---|---|
| **满分率** | **约 9pp** | **约 11pp** |
| 有进展率 | 约 9pp | 约 12pp |
| 平均分 | 约 0.17 分 | 约 0.17 分 |

即：ID 满分率差 9pp 以上才算有证据，实测差 2–3pp 就是分辨不出。**规划用例规模时按这组值的 1.5 倍**（要求"下次重测也还显著"，ID 满分率约 13pp）。

> 💡 **下限由两件事决定**：用例数 $n$，和用例级差值标准差 $SD_d$（只能从当期数据算）。**$SD_d$ 越大门槛越大，用例数越多门槛越小**——公式、查表、本评测集的 $SD_d$ 实际范围见 **A4**。
>
> 上表为 12 个模型两两配对的中位值，**实际分析一律用当期数据重算**（不同模型对的下限在 ID 6–12pp、OOD 7–17pp 间波动）。

> ❗ **样本量不足时就写"证据不足"。** 换检验方法、放宽 $\alpha$、改用单侧、按执行数算 n —— 这些都不会让证据变强，只会让结论站不住。扩充用例数也收益有限：**门槛只随 $\sqrt{n}$ 缩小**，用例翻一倍门槛仅降 28%（见 A4）。
>
> **唯一的低成本出路是跨轮累积**：同方向结论连续两三轮出现，比任何单轮的显著都硬。建个表存历史结果即可，不增加测试成本。

## 五、报告措辞

> 📝 **把"不显著"改写成置信区间 + 方向计数。** 例："退步 7pp，90% 区间 [-19.8, +5.0]，27 个用例中 11 降 6 升 10 平——方向偏向退步，幅度不确定"。
>
> 原因：非统计读者把"不显著"一律理解成"没差别"，而"点估计退步 7pp 但证据不够硬"与"没差别"是完全不同的结论。

| | 写法 |
|---|---|
| ❌ | "两个模型在 OOD 上无差异"（不显著 ≠ 无差异） |
| ❌ | "某 skill 提升 60pp，能力明显改善"（实为 1 个用例成功次数 2→5） |
| ✅ | "指标差值为 Δ，区间为 [L, U]，p 值为 P；N 个用例中 K 个上升、J 个下降，其余持平。根据区间、p 值和方向计数描述结果" |

### 必报四项

| 项 | 例 | 作用 |
|---|---|---|
| **指标差值** | -7.0pp | 差多少 |
| **90% 置信区间** | [-19.8, +5.0]pp | 真实差异的可能范围。**同时含方向与幅度，信息量最全** |
| **p 值** | p=0.32（配对 t，双侧） | 可不可信，须标注检验方法 |
| **方向计数** | 11 降 / 6 升 / 10 平 | 差异是普遍存在还是只来自少数用例 |

> 💡 **置信区间必须与 $\alpha$ 配套**：$\alpha$=0.10 对应 **90% 区间**。这样"区间跨不跨 0"与"p 是否小于 0.10"完全一致，不会出现矛盾表述。
>
> **不得为了让区间不跨 0 而调低置信水平**——报 80% 区间等于把门槛悄悄放宽到 0.20。

### 其他硬性规则

- **一律双侧。** 单侧只在测前已独立定死方向时才合法；"看到降了所以检验是否降"等于把 $\alpha$ 翻倍
- **预先声明主结论切面**（通常是 ID 与总 OOD × 满分率）。每个切面都是一次检验，$\alpha$=0.10 下 20 次检验在真无差异时至少蹦出一个"显著"的概率约 88%；子类分析标为探索性
- **用例数 <15 的切面**只报点估计，不报 p 值
- **必报 0/1/2 三档分布**——满分率相同但失败形态不同，只有它能看出来

## 附录

### A7. ID vs OOD 为何不可检验

ID 与 OOD 是独立设计的两批用例。两样本检验技术上能给出 p 值，但它回答的是"这两批用例的分数分布是否同源"——而它们本来就不同源，题不一样。测到的差距里混着"分布偏移导致的退化"和"这批题本来更难"，在独立设计的 OOD 下**无法拆开**。

**但两个模型的 ID-OOD 落差可以比较**：题目难度对两模型是同一套，被消掉了。做法是对 ID 集配对差值集合与 OOD 集配对差值集合做两样本 t 检验，等价于检验模型 × 分布的交互效应。这是当前数据结构下唯一干净的泛化结论。

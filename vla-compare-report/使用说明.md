# VLA 模型对比报告工具包 · 使用说明

## 准备（只需一次）

- 安装 Node.js 18 或更高版本：https://nodejs.org
- 安装 Python 3，再装依赖：`pip3 install numpy scipy`
- 一个能读写本地文件、能跑命令的 AI 编程助手，例如 Claude Code、Codex、Cursor。只能聊天、不能执行命令的 AI 网页版不行。
- 想直接读多维表格（方式一）时，还需要 `lark-cli` 可用并已登录。

## 出哪种报告

两种模板，用 `--type` 选，默认是双对比：

| 模板 | 说明 | 命令 |
|---|---|---|
| 双对比测试报告（默认） | 一个基准对 1–7 个模型：两模型、三模型，或 4 个以上的 N 模型（基准 vs 每个） | `--models "基线" "新模型"`，多模型继续往后加 |
| 单测试报告 | 只看一个模型的水平，没有差值和 p 值 | `--models "模型名" --type single` |

```bash
node cli.js --templates          # 列出模板
```

段变化、步数升级这类对比不用换模板：数据形状和统计口径跟双对比一样，只改标题和第 3 节测试配置。

## 出一份报告

### 方式一：直接读多维表格（推荐，不用导表）

数据还在飞书多维表格里时，跳过下载这一步，程序直接读：

```bash
node cli.js --base-w <白盒多维表格链接或token> --base-b <黑盒多维表格链接或token> \
  --models "基线模型" "新模型" --labels "基线短名" "新模型短名" --out <输出目录>

# 报告里用短名：--labels 按 --models 顺序给（如 模型A / 模型B）；不给则用全名
```

两本表可以贴 wiki 链接，程序自动解析。表格链接由使用者提供：

- 白盒《基模测试记录》：用户提供
- 黑盒《基模黑盒场景测试记录》：用户提供

要求：本机能跑 `lark-cli` 且已登录，登录账号对这两本多维表格有读权限。跑一次约 8 秒（4 个子表、约 480 个用例、1000+ 次执行）。表里新增模型只要按「一个子表一个模型、列名照大表」的规矩建，不用改代码。

### 方式二：用导出的 xlsx

1. 从飞书下载两本大表：《基模测试记录.xlsx》（白盒）和《基模黑盒场景测试记录.xlsx》（黑盒），放进本文件夹的 `数据/` 里。
2. 用 AI 助手打开本文件夹（Claude Code：在文件夹里运行 `claude`，或在桌面版里选这个文件夹）。
3. 对它说，例如：

   > 用我提供的两个表出报告，基线是模型A，新模型是模型B。

   不知道模型名就说「列出表里有哪些模型」。测试配置想填进报告第 3 节的话，在对话里一并给它（文字或截图）；没给就只留空模板。
4. 报告放在桌面，文件名带时间戳：`~/Desktop/<标题>_YYYYMMDD-HHMM.md`。数字底稿和 Excel 复核表在 `报告输出/<标题>/work_YYYYMMDD-HHMM/`。改数字时会重新生成一份新时间戳的报告，旧版保留不动。

AI 会自动读取文件夹里的 `AGENTS.md` / `CLAUDE.md`，按固定流程执行：程序出数 → Python 独立复算 → 写报告 → 程序核对报告里的每一个数字。数字全部来自程序，AI 只负责组织文字。

## 计算文件指纹锁（防止口径被顺手改）

`math.js`、`analyze.js`、`native.js`、`report.js`、`excel.js`、`verify.py`、`crosscheck.py`，以及所有 `engine/report_*.js` 渲染器，它们的 SHA-256 记在 `compute-lock.json` 里。`cli.js` 每次启动先比对，对不上就直接退出、不出任何数字。

```bash
node cli.js --lock-status                                  # 看每个文件是否一致、最近一次变更
node cli.js --relock --reason "改了X口径，因为Y"            # 确认变更并留痕
```

- 这是给"数字只能从程序出"加的一道程序闸门，不是安全防护：它挡不住有权限的人，但能让每一次改动都必须写明原因，并记进 `compute-lock.json` 的 `history`。
- **扩展报告类型不需要动被锁的文件**：新建 `engine/report_<类型>.js`，在 `templates.js` 注册，再 `--relock --reason "新增 X 渲染器"` 登记一次。
- 它和程序原有的数据指纹是一对：数据指纹证明"进来的数据没变"，文件指纹证明"算它的代码没变"。同代码 + 同数据 → 同结果。

## 只想核对数字（不用 AI）

运行 `node server.js`，用浏览器打开 `http://localhost:8770`，拖入两本大表、选模型，可以看全部指标，也可以上传报告 .md 核对数字。注意：同一局域网的其他人也能打开这个页面（页面没有登录），但表格只在各自浏览器里计算，不会上传。
